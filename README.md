# Excel content add-in: Extensible Content

## Summary

This is a content add-in that embeds a browser frame in an excel spreadsheet.  User editable HTML, CSS, and Javascript can be used to display a variety of content or interact with the Office.js API.

## Applies to

- Excel on Windows
- Excel on Mac
- Excel on the web

## Prerequisites

- Excel on Windows with a minimum build of 16.0.14626.10000, or Excel on Mac with a minimum build of 16.55.21102600, or Excel on the web.
